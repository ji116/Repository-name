# 坦克大战 · Battle City

一个用原生 HTML + Canvas + JavaScript 实现的经典《坦克大战》(Battle City) 网页小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制己方坦克，消灭所有敌方坦克并**保护基地（老鹰）不被摧毁**。
- 敌方坦克会从顶部 3 个出生点不断出现，并向你的基地逼近。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |
| `Enter` | 开始游戏 |

## 地图元素

- 🧱 **砖墙**：可被子弹摧毁
- ⚙️ **钢墙**：只有满火力（3 级）才能摧毁
- 🌊 **水**：坦克无法通过，子弹可以穿过
- 🌲 **草丛**：坦克可躲藏其中，子弹可穿过

## 道具

| 图标 | 效果 |
| --- | --- |
| `S` | 火力 +1（最多 3 级，满级可击穿钢墙） |
| `G` | 手雷：消灭场上所有敌人 |
| `L` | 生命 +1 |
| `H` | 铁铲：基地周围砖墙临时变为钢墙 |
| `T` | 冻结：敌方坦克定身一段时间 |
| `D` | 护盾：己方坦克短暂无敌 |

## 运行

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 技术要点

- 单文件实现，无外部依赖，纯 Canvas 渲染。
- 基于格网对齐的坦克移动，可平滑滑入单格通道。
- 敌人 AI：随机转向 + 朝玩家方向偏向 + 碰撞避让。
- Web Audio API 生成射击 / 爆炸 / 道具等音效。
